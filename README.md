# CEHO-MSA
CEHO-MSA: A Clustering-Guided Elephant Herding Optimization Framework for Progressive Multiple Sequence Alignment

Abstract
Multiple Sequence Alignment (MSA) is a fundamental task in bioinformatics, yet accurately aligning diverse biological sequences remains challenging because of sequence variability, evolutionary divergence, and the conflicting objectives involved in alignment quality. This study introduces CEHO-MSA, a clustering-guided Elephant Herding Optimization framework that combines alignment-free sequence characterization, graph-based clustering, progressive profile alignment, and population-based refinement within a unified MSA strategy. The framework first represents sequences using k-mer frequency profiles and partitions them through an adaptive graph-based clustering procedure. Progressive profile alignment is then performed within clusters, followed by profile-level merging to construct a structured seed alignment. Elephant Herding Optimization subsequently refines this alignment through a gap-insertion representation that preserves the original residue order and sequence content.
CEHO-MSA was evaluated against classical, metaheuristic, and clustering-based MSA methods using complementary alignment-quality measures, including Sum-of-Pairs (SP), normalized Sum-of-Pairs (SP-Norm), Exact Match (EM), Alignment Length (AL), Column Score (CS), Average Shannon Entropy (AvgEntropy), and Gap Percentage (GapPercent). Across the principal benchmark sets, CEHO-MSA showed particularly consistent performance in SP, SP-Norm, CS, and AvgEntropy. In comparisons with metaheuristic methods, it achieved the preferable value in 67.6% of the evaluated dataset–metric comparisons, increasing to 75.7% against clustering-based methods. Reference-guided evaluation across 24 benchmark instances further showed a mean Total Column (TC) of 0.7623, the highest among the compared methods, while the higher gap percentage indicated a trade-off between column conservation and gap usage. Statistical analysis confirmed significant differences in SPS (Sum-of-Pairs Score w.r.t. reference alignment) and TC against most competing methods, with substantial effect sizes in several comparisons. Overall, CEHO-MSA provides a quality-oriented and structured optimization framework for progressive MSA, while maintaining a computational profile between lightweight classical aligners and more resource-intensive optimization-based approaches.

Keywords: Bioinformatics, Multiple Sequence Alignment, Clustering, Elephant Herding Optimization, Progressive Multiple Sequence Alignment.
